# h728/a523/x96qpro+ hacky patches.

Various patches that bring up HDMI, ethernet, and MMC on the h728 board.

Also some patches attempting to add video encoding (cedrus) for this board,
that I haven't tested yet.

The h728 uses the same die as a523, so they are used interchangably here.

The board is also referred to as the x96qproplus in some hardware listings.

This may or may not work for you.

These patches are based on linux-next as of June 29, 2026.
